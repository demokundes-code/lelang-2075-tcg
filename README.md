# Lelang 2075 TCG

Versi ini dibuat sebagai halaman statis yang siap di-publish ke GitHub Pages.

## Cara preview lokal

1. Buka folder proyek.
2. Jalankan server lokal, misalnya:
   ```bash
   python -m http.server 8000
   ```
3. Buka browser ke:
   ```text
   http://localhost:8000
   ```

## Struktur file

- `index.html` – struktur halaman
- `styles.css` – styling utama
- `app.js` – logika permainan, audio, dan interaksi

## Catatan

- GitHub Pages akan bekerja paling baik jika repo dipublikasikan dengan branch `main` dan file utama berada di root.
- Audio akan aktif setelah pengguna melakukan klik/tap pertama kali pada halaman.
- Fitur aksesibilitas ditambahkan untuk keyboard dan pembaca layar.
